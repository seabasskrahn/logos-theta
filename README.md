# logos-theta — retirement notice only

This repository exists for one reason: to serve a single retirement notice at
**https://seabasskrahn.github.io/logos-theta/**

The retired Logos Theta Android app was configured to load its screen from that address
(`capacitor.config.json` → `server.url`). The project was renamed, so GitHub Pages stopped answering there
and installed copies of the app saw a "Site not found" page or fell back to their own older bundled build.
This page replaces that with a plain, honest notice and a link to the current build.

**There is no application code here.** `index.html` is static, loads nothing from anywhere else, plays no
audio and does not track anyone.

- **Current build:** https://seabasskrahn.github.io/sonolumina/
- **Earlier build, kept for the record:** https://seabasskrahn.github.io/sonolumina-build/ (formerly this name)

The retired app packages (`apk-v1` … `apk-v4`) were unpublished on 2026-10-20 and their download files removed.
The original files are archived; nothing was deleted.
